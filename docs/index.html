Open Mathematics Lab · Problem 001

The perfect cuboid

Does there exist a box with positive integer edges a, b, c, integer face diagonals and an integer space diagonal? Nobody knows. This page is a research log with explicit status labels, not a claimed solution.

Problem status: open Source on GitHub
Read this first. Nothing here proves or disproves the existence of a perfect cuboid. The results are restrictions on sub-cases and finite computations. Several arguments are human-readable proofs that have not been formalised, and novelty relative to the literature has not been established.

A finite search never shows non-existence. These numbers only show that no small counterexample exists.
